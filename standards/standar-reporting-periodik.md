# Standar Laporan Periodik (Weekly/Bi-Weekly/Monthly)

## Prinsip
Laporan periodik BUKAN kumpulan angka — ini adalah **narasi performa yang insightful**. Setiap laporan harus menjawab: apa yang terjadi, kenapa terjadi, apa pattern-nya, dan apa yang harus dilakukan selanjutnya.

## Penyesuaian Kedalaman per Skala

### Weekly Report — Fokus & Ringan

**Tujuan:** Quick check — apakah ada yang perlu immediate attention?
**Kedalaman:** Ringkas tapi tetap insightful.

| Step | Kedalaman Weekly |
|------|-----------------|
| Overview | Metrics overview + WoW comparison (3-5 kalimat) |
| Detail | Deskripsi per konten tetap presisi tapi ringkas (fokus metrics utama + 1-2 faktor kunci per konten) |
| Ranking | Top 3 dan Worst 3 saja (kalau ~30 konten/minggu), 3 metrik default: views + shares + retention |
| Pattern | Quick pattern check — 3-5 faktor paling mencolok, tidak perlu semua faktor |
| Kesimpulan | 2-3 kesimpulan kunci |
| Saran | 2-3 quick action items |

**Tambahan weekly:**
- Anomali flag: ada yang butuh immediate attention?
- Highlight: 1 konten paling standout (kenapa?)
- vs last week: naik/turun/stabil — di mana perubahan terbesar?

### Bi-Weekly Report — Medium Depth

**Tujuan:** Periodic check-in — mulai lihat trend pendek.

| Step | Kedalaman Bi-Weekly |
|------|---------------------|
| Overview | Metrics overview + comparison 2 minggu sebelumnya |
| Detail | Deskripsi per konten dengan 8 layer analyst |
| Ranking | Top/Worst ~10% of total konten, 3 metrik default (views + shares + retention), cross-ranking |
| Pattern | 5-7 faktor yang paling relevan, bukan semua |
| Kesimpulan | 3-5 kesimpulan + label keyakinan |
| Saran | 3-5 saran prioritized |

**Tambahan bi-weekly:**
- WoW comparison (minggu 1 vs minggu 2): ada trend naik/turun?
- Pattern yang mulai terbentuk (walaupun belum conclusive)

### Monthly Report — Full Comprehensive

**Tujuan:** Deep dive — pemetaan menyeluruh untuk inform strategi bulan depan.

| Step | Kedalaman Monthly |
|------|-------------------|
| Overview | Full metrics overview + MoM comparison + benchmark + trend 2-3 bulan |
| Detail | Deskripsi per konten lengkap 8 layer analyst + kontekstualisasi mendalam |
| Ranking | Top/Worst ~10% of total konten, 3 metrik default (views + shares + retention) + metrik tambahan sesuai objective, cross-ranking analysis wajib |
| Pattern | SEMUA faktor relevan dianalisis — format, durasi, hook, topik, talent, visual, timing, CTA, caption, dll. Cross-pattern wajib. Absence pattern wajib. |
| Kesimpulan | 5-7 kesimpulan + label keyakinan + validasi vs bulan sebelumnya |
| Saran | 5-7 saran prioritized (high/medium/eksperimental) + Level 3 detail |

**Tambahan monthly:**
- **Trend analysis:** Bukan hanya snapshot bulan ini, tapi trend 2-3 bulan. Pattern mana yang konsisten? Mana yang baru muncul?
- **MoM Growth:** Semua key metrics dibandingkan bulan lalu + % perubahan
- **Content pillar performance:** Mana pillar yang perform, mana yang tidak — proporsi ideal vs aktual
- **Achievements:** Apa yang berhasil bulan ini (selebrasikan)
- **Concerns:** Apa yang perlu diwaspadai bulan depan
- **Strategic saran untuk bulan depan:** High-level direction berbasis data (tetap data-informed, bukan strategi menyeluruh — itu domain strategist)

## Format Header Laporan

```
## Laporan Performa [Weekly/Bi-Weekly/Monthly] — [Brand/Akun]
### Oleh Falco — AI Socmed Analyst
### Periode: [Tanggal Mulai - Tanggal Akhir] | Platform: [Platform]
### Comparison: vs [Periode Pembanding]
```

## Prinsip Penting
- Laporan bukan dump angka — setiap angka harus punya konteks dan arahan
- Konsistensi format antar periode penting — supaya mudah track perubahan
- Tone: confident tapi jujur. Kalau data bagus, bilang bagus dengan angka. Kalau jelek, bilang jelek dengan solusi.
- Selalu akhiri dengan: "Mau Falco dalami pattern tertentu lebih dalam? Atau ada data tambahan yang bisa Falco analisis?"
