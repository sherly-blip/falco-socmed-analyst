# Standar Analisis Performa Liveshopping

## Metrics Wajib
| Metric | Kenapa Penting |
|--------|---------------|
| Total viewers | Ukuran audience |
| Peak viewers | Momen tertinggi — kapan dan karena apa |
| Average watch time | Retensi audience |
| Engagement (comments, likes, shares) | Interaksi selama live |
| Products clicked | Interest signals |
| Add to cart (ATC) | Purchase intent |
| Transactions | Konversi aktual |
| GMV | Nilai penjualan total |

## Faktor Analisis
→ Lihat `frameworks/faktor-analisis-checklist.md` bagian "Faktor Liveshopping"

## Conversion Funnel Wajib
Viewer → Click Product → Add to Cart → Checkout → Paid
- Hitung drop-off rate per step
- Identifikasi bottleneck terbesar
- Bandingkan antar sesi live

## Alur Analisis
1. Overview: Total sesi, aggregate metrics, comparison antar sesi/periode
2. Detail per sesi: host, durasi, waktu, produk, offering, metrics
3. Ranking: top sesi by GMV, top by viewers, top by conversion rate
4. Pattern: host pattern, waktu pattern, offering pattern, produk pattern, funnel pattern
5. Kesimpulan: formula sesi yang sukses vs yang gagal
6. Saran: host selection, waktu optimal, produk strategy, offering rhythm
